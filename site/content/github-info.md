## Awesome Copilot resources

Source: [awesome-copilot.github.com](https://awesome-copilot.github.com/)

Note: the site no longer has a dedicated `/workflows/` section (that URL now 404s). Community content is now organized under **Agents** (222 custom agents for specialized Copilot experiences), **Instructions** (coding standards/best practices), **Skills** (self-contained instruction+resource folders), **Plugins**, **Canvas Extensions**, and a **Learning Hub**. For workflow-style automation examples, the closest match is the [Agents](https://awesome-copilot.github.com/agents/) catalog and the [Skills](https://awesome-copilot.github.com/skills/) catalog — both browsable and installable directly into VS Code, VS Code Insiders, or GitHub.
